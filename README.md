# Project Collection

This repository contains multiple full-stack projects. Each project is provided in a separate folder/archive with its own frontend and backend source code.

## Before You Run Any Project

Please extract the project (if it is provided as a ZIP file) and follow the steps below.

### Frontend

Navigate to the frontend directory and install the required dependencies:

npm install

Start the development server:

npm run dev

### Backend

Navigate to the backend directory and install the required dependencies:

npm install

Start the backend server:

npm start

> **Note:** Some projects may use a different start command such as `npm run dev`. Please refer to the project's configuration if needed.

Please review each project's source code and configuration files before running it.
